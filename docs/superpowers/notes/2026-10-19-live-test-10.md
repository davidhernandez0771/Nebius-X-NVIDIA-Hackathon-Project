# How to start live test #10 on `pm/live-10`

Branch `pm/live-10` (worktree `C:\dev\pm-t6`), from T7's full trial `pm/merge-trial-site-full`.

**What's on it:**
- **Record:** the hologram page (`web/src/site/record`) at `/record`. `/pm/record` redirects there, keeping
  the query and the hash.
- **Hand lock:** #13's, as it was. The camera canvas draws the chip, and the V sign re-picks.
- **Robot twin:** T1's 3D twin is in the workspace pane. It runs live from the sim when the sink streams, and
  otherwise replays `web/public/world/demo-episode.json`. The pane's tag (`LIVE` / `REPLAY`) and the caption
  under the view say which one is showing.

One Isaac process at a time: stop the sim worker and any eval first. Then open four terminals from `C:\dev\pm-t6`.

1. **Backend + relay** (the relay is part of the backend: `/ws/teleop`, `/teleop/status`):
   ```
   uv run uvicorn app.main:app --reload --app-dir src --port 8000
   ```
   Check it: http://127.0.0.1:8000/teleop/status answers.
2. **Sink** (Isaac Lab, with the Kit window). It connects to `ws://127.0.0.1:8000/ws/teleop?role=sim` and also
   feeds the twin:
   ```
   $env:PYTHONPATH="C:\dev\pm-t6\src"
   C:\isaac\env_isaaclab\Scripts\python.exe sim_worker\scripts\teleop_sink.py --viz kit
   ```
   It saves demos under `DATA_DIR` (or pass `--data-dir`).
3. **Web:**
   ```
   npm --prefix web run dev
   ```
4. **Open** http://localhost:5173/record. The old link http://localhost:5173/pm/record lands on the same page.
   - Add `?latency=1` only if you want the per-stage latency trace.
   - The debug trace is always in the settings drawer (the gear).
   - Click **Start camera** in the camera pane.

## What to check

- **Twin:**
  - Before the sink is up, the workspace pane says `REPLAY` and plays the verified copy.
  - Once the sink connects, it switches to `LIVE` and follows the arm in the Kit window, camera on or off.
  - This is the first time anyone watches the live twin with Isaac.
  - If it stays on `REPLAY` with the sink connected, check that the sink is this branch's
    (`sim_worker/teleop_session.py` sends `sim_twin`).
- **Hand lock:** the checklist in [2026-10-18-hand-lock.md](2026-10-18-hand-lock.md), "What to try in the next
  live test":
  - one hand locks after ~0.3 s;
  - a second hand moves nothing;
  - short losses hold the pose, long ones say "lost";
  - the V sign re-picks;
  - a debug trace with both hands in view comes from the settings drawer.
- **Recording:** record, stop and save, then use the Review link in the bottom strip.
