  404 without CORS, so every backend call failed the way it would on a judge's machine.
- **What each script checked:**

    numbers on each page;

  - the Tab order in the room.
- **Every route:**

    (both views), `/site/results` (`#proof` too), `/test-track` (each source, a failed seed, Keys), `/robots`,
    `/robots/setup`, `/review2`, `/pm/review`, `/pm/dataset`, `/design`;
  - unknown routes (`/nope-404`, `/site`);
  - `/`: the whole intro in half-viewport steps, every proof beat;
  - the rail's WORKSHOP and Skip the intro;
  - every place (shelf → a cartridge's detail, machine → into the projection → `/record` → Back to workshop,
    bench, wall → Franka's close-up);

- **Scripts:** in my session scratchpad (`…\scratchpad\sb\*.mjs`), not committed.
- **The source grep:** "hasn't run", "not run yet", TODO, "coming soon", 15/40 or 17/40 presented as the latest
  result.

**No console errors or warnings anywhere** (only React Router's two future-flag warnings), before or after. **No
horizontal page scroll** on any route at either size. No broken images, no 404 assets or JSON. The only failed
requests are the backend's (`:8000`), as expected offline.
