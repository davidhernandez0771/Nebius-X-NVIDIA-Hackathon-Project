## 3. Backend (`src/app/routers/*.py`, `sim_worker/server.py`)

**Path traversal:**
- **How it was checked:**
  - every GET route with a path parameter was fuzzed (TestClient) with `..`, `%2e%2e`, `..%2F..%2Fsecret`, `%2Fetc%2Fpasswd` and `..%5C`. **No 200 and no 500.**
  - Names are checked by `fullmatch` regexes (`showcase._NAME`, `store._SAFE_ID`, `recipe._ID`, `byor_store.ROBOT_ID`), plus `resolve()`/`is_relative_to` (`storage.scan_path`, `analysis`, `flow`, `byor_store.resolve_mesh`).
- **Robot `.zip` upload:** it rejects absolute paths, `..`, drive letters and symlinks. It caps both the file count and the unpacked size.

**Uploads:**
- **Photos:** limited by content type and capped at 20 MB, stored under uuid names.
- **Scans:** limited to `.glb` and 200 MB, stored under uuid names.
- **Minor (local only):** `/phone-scans` has no per-photo size cap, and `upload_photo` reads the whole body before checking the size.

**SQL:** SQLAlchemy ORM only. There is no raw or string-formatted SQL.

**Errors:**
- `TokenFactoryError` / `Reali3Error` messages are returned in 502s. They hold the status code and the provider's message, never the key.
- `/analysis` hides the details.
- There are no debug flags.

**CORS:** `config.cors_origins()` allows only `http://localhost|127.0.0.1:<port>`, with no credentials.

## Fixes made

| File | Change |
|---|---|
| `src/app/main.py` | New `OriginGuard` ASGI middleware (details below) |
| `sim_worker/server.py` | A POST that carries an `Origin` header (i.e. from a browser) gets 403. The backend's httpx client sends none. |
| `tests/test_security_origin.py` | 10 tests covering both fixes (details below) |
| `.gitignore` | Defensive patterns (section 2) |

**`OriginGuard` (`src/app/main.py`):**
- **Writes:** a POST/PUT/PATCH/DELETE whose `Origin` is not in `cors_origins()` gets 403 before any handler runs. This includes `Origin: null` and look-alikes such as `http://localhost.evil.example:5173`.
- **Websockets:** a websocket with such an `Origin` is closed with 1008.
- **Unchanged:** requests with no `Origin` (curl, scripts, the teleop sim client, tests), GETs, and the dev site at `:5173`.
- **Headers:** every response gets `X-Content-Type-Options: nosniff`.
- **Why it was needed:** CORS only hides the answer from a foreign page. A form POST to `http://localhost:8000/api/photos/1/analyze` would still spend credits.

**`tests/test_security_origin.py`:**
- **Covers:**
  - cross-site POST → 403;
  - `null` and look-alike origins → 403;
  - the dev origin and no origin still reach the handler;
  - GET is not blocked;
  - preflight still works;
  - the nosniff header;
  - the websocket is refused with 1008 while the dev origin and no origin reach the handler;
  - sim worker browser POST → 403.
- **Red then green:** 5 tests failed before the fix and pass after it.

## Deploy note

The backend has no auth (`DEV_OWNER_ID`). It is meant to run on localhost.

**If any backend is ever reachable from the internet:**
- Keep `SANT_ANALYST_LIVE` and `SANT_PIPELINE` **unset/off**.
- Do **not** set `NEBIUS_API_KEY` or `REALI3_API_KEY` on that host. `/api/ask`, `/api/chat`, `/api/organize`, `/api/photos/*/analyze`, `/scenes/create`, `/demos/*/diagnose` and `/phone-scans` would let anyone spend them. Without the keys they return 502/503.
- Keep `sim_worker` on `127.0.0.1` (never `--host 0.0.0.0`).
- `SANT_CORS_ORIGINS` accepts only local http origins by design.

**A static deploy** of `web/dist` (the site plus `proofData`/`results.json`) has none of these risks.
