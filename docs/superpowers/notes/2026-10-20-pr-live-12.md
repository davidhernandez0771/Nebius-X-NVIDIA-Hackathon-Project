## Title

SANT: human demos end to end (record → physics → repair → multiply → train), the 3D site, and honest results

## Summary

This branch takes SANT from scripted demos to **real human demos**:
- It records them live into Isaac Lab by webcam, keyboard or mouse.
- It checks each one in physics, repairs it (rules or Nemotron edits), multiplies it into verified copies, and trains
  and evaluates ACT on the result.
- Every result is pre-registered and reported as measured, including the ones that don't favour SANT.

It also lands the new site: a 3D descent from the tesseract hero into the workshop, with the robot wall, the machine,
the bench and the data showcase.

### Pipeline (src/demo_pipeline, sim_worker, sim_eval, lerobot_tools, scripts)
- **Achieved-path replay:** replay what the arm reached, not what was commanded. This made human replays meaningful.
- **Neaten ops** for human failures: `recenter_grasp`, `release_above_bin`, the trim and smooth fixes.
- **The Nemotron repairer:** Nemotron 3.5 Super VL writes trajectory edits from the simulator's measurements. Code
  caps each edit, and physics verifies it. It comes with two blind, pre-registered A/Bs against the rules, and a
  hybrid repairer (rules first, then Nemotron where they fail).
- **Human-demo experiment runner** (`scripts/run_human_demo_experiment.py`): select → physics → repair → align →
  multiply → grid → train → eval → results, resumable, under `gpu.lock`, with its own pre-registration file.
- **Mimic export:** verified demos become Isaac Lab Mimic HDF5, with a SANT Mimic env, run on this Windows PC.
- **Import guard** (`sim_worker/own_code.py`): every Isaac and LeRobot entry point runs its own checkout's code and
  says so at startup.
- **Coverage report:** verified data per scene of the task set, compared with the eval distribution.
- **Practice-and-correct loop:**
  - failure moments from the verdict signals;
  - a 1 s rewind;
  - scripted retakes plus a human retake queue (`GET /corrections/queue`);
  - a `corrections_<k>` cell.
- **Policy fixes** (all off by default):
  - eval-time options: binarize the gripper, `--n-action-steps`, temporal ensembling;
  - training options: shift augmentation, ResNet dilation, a 100k-step budget;
  - checkpoint selection on practice seeds (`eval_cells --select-steps`).
- **SANT data fixes** (all off by default): the multiplier's yaw wrap, a grasp-retime Neaten op for swoop grasps, and
  a centred approach at the hover.

## Results (measured; each is in its note)

**Scripted demos** (from before this branch, for reference): 10 demos alone **3/40** vs 10 + 100 verified copies
**17/40** on unseen scenes, Fisher **p = 0.0005**. A separately trained 10 × 30 set gave 16/40.

**Real webcam demos** (live test #10, one person, 10 demos):
- **Physics as recorded:** **0/10** pass. The gripper pressed into the bin while placing (9/10, up to 927 N against a
  5 N limit).
- **Rules repair → multiply:** **3/10** repaired → **24/30** copies verified.
- **Blind repair A/B, Nemotron edits vs rules:** **5/10 vs 3/10** (McNemar p = 0.50, $0.21). The pre-registered re-run
  gave **2/10 vs 3/10** (p = 1.0, $0.28). **Not significant, and it did not replicate**: Nemotron's plans vary from
  run to run.
- **Training on SANT's output** (27 episodes from 3 repaired demos), one arm: **3/40** (Wilson 2.6–19.9%). Drops
  dominate. It is not a comparison.

**Real mouse demos** (live test #11, the same person, 10 demos, pre-registered):
- **Physics:** 10/10 pass live and 10/10 on replay (0 N). 10/10 cleaned up, **100/100** copies verified.
- **Raw vs SANT:** raw **0/40** (0–8.8%) vs SANT **3/40** (2.6–19.9%), two-sided Fisher **p = 0.24, not significant**.
  - SANT's policy gets the cube into its fingers (26/40 lose it before the bin; raw has no drops).
  - But it hits the bin or table above 5 N in 27/40 episodes; raw does in 2/40.
- **The soft floor did not cause that:** no training label goes more than 3.7 mm under it (T6). The collisions' cause
  is still open.
- **A limitation:** all 10 demos were recorded in one scene, and the eval uses 40 random scenes.

**Isaac Lab Mimic on SANT's repaired demos:** SANT verified Mimic's output at the same rate as its own multiplier,
**82% vs 80%** (91/111 vs 24/30, p = 0.79). SANT's check rejected 9 of Mimic's 100 self-reported successes. SANT's
side is its existing 24/30; the planned matched run was not done.

**Nemotron as labeler / judge** (pre-registered, earlier): **40/40** and **59/60**, tied with code baselines. Physics
decides.

**Not shown:** that SANT's data trains a better policy from human demos. The only two-arm human test is not
significant. The README and submission docs say so.
