## Title

SANT: RL teacher distilled into the camera policy, with a pre-registered final test (15/40; the 60% goal not met)

## Summary

This PR adds the **RL teacher** and **distillation** track, and the pre-registered test of it.
- An Isaac Lab PPO teacher learns the cube-in-bin task from a `check_success`-style reward, starting from SANT's
  verified human demos.
- Its rollouts, mixed with the SANT mouse data, train the same camera ACT student as before.
- The student was tested **once** on the held-out seeds 5020–5059. It scored **15/40**:
  - **up from** SANT alone (3/40) and raw demos (0/40), both significant;
  - **short of** the 60% goal;
  - level with the scripted multiply (17/40), which is a reference only.

Every decision rule, amendment and disclosure was written down before the data it governs. The whole record is in
[2026-10-21-distill-prereg.md](2026-10-21-distill-prereg.md).

- **Why the first round failed:** the root cause of the 0/30 was teacher labels the student's actuator couldn't
  execute. Amendment 4 made the teacher run with the student's actuator.

**The final test, run once on 5020–5059:**

| | Result |
|---|---|
| **Success** | **15/40 (37.5%), Wilson 95% CI 0.242–0.530** |
| **Goal ≥ 24/40 (60%)** | **not met** |
| vs mouse SANT 3/40 (two-sided Fisher) | p = 0.0025, significant |
| vs mouse raw 0/40 | p = 1.2 × 10⁻⁵, significant |
| scripted multiply 17/40 (a reference only) | p = 0.82, no detectable difference |

- **The failures:** all 25 ended at the time limit, and every one includes a dropped cube. Grasp retention is still
  the bottleneck.
- **Selection vs test:** selection's 21/29 vs the test's 15/40 is a real gap (Fisher p = 0.007).
  - Part of it is the winner's curse: the better of two candidates, picked on the seeds it is scored on.
  - T6's analysis (same scene sampler, scene features, bin side, run conditions) found no mechanism.
  - The test number stands as run.
- **The test seeds are now spent.** Any follow-up is a new experiment, with its own pre-registration and fresh seeds.
